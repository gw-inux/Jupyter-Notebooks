Start with **one particle**. Predict left or right at each peg, then press **Run highlighted particles**. The animation starts immediately. Use **Pause**, then **Previous step** or **Next step** to examine a decision. When paused, the progress bar becomes a slider for moving backward or forward. **Start** returns to the start; **Final result** shows the end.

Observe the two plots directly below the board: **Where does it arrive? When does it arrive?** Every step takes 1 s. Different paths therefore change the outlet position but not the arrival time. With only a few particles, the outlet distribution will be irregular; the exact binomial reference describes many repetitions (see the Galton-board explanation above).

After this first experiment, continue to **Pinboard experiment** to add a larger population and vary travel times.

The animation targets about **8 screen seconds**; the model travel time remains **20 s**. Optional steering controls are collapsed below Run. The empty board in **Observe the transport** marks where the animation will appear.

The smaller framed board is a **preview**. Run brings Observe the transport into view, keeping the Run/Rerun button visible. After the first run, **Rerun highlighted particles** starts a new realization with the current settings; **Play** replays the current result. A new random sample may still reach the same outlets.
