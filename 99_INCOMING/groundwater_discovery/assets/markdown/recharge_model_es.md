Recarga R y conductividad K uniformes; base horizontal impermeable z_b = −10 m; costa x = 0, divisoria interior x = L = 200 m. h se mide sobre el mar. La aproximación de Dupuit ignora diferencias verticales de carga. El espesor saturado es h − z_b, por lo que la transmisividad varía con h.

Condiciones: h(0) = 0 y dh/dx(L) = 0. El caudal estacionario por metro de costa es R × L. Se convierten mm/año a m/día con 365,25 días/año. Se excluyen agua salada, bombeo, almacenamiento transitorio y límite topográfico. Es un modelo educativo de una densidad, no un modelo costero completo.
