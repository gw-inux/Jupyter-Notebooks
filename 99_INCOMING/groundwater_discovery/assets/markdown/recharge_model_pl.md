Stałe zasilanie R i współczynnik filtracji K; poziome nieprzepuszczalne podłoże z_b = −10 m; brzeg x = 0, dział wód x = L = 200 m. h mierzymy względem morza. Przybliżenie Dupuita pomija pionowe różnice potencjału. Miąższość nasycona wynosi h − z_b, więc przewodność warstwy zależy od h.

Warunki brzegowe: h(0) = 0 i dh/dx(L) = 0. Odpływ ustalony na metr brzegu wynosi R × L. Przeliczenie mm/rok na m/d używa 365,25 dni/rok. Model pomija wodę słoną, pompowanie, zmiany retencji w czasie i ograniczenie powierzchnią terenu. To dydaktyczny model o jednej gęstości, nie pełny model wybrzeża.
