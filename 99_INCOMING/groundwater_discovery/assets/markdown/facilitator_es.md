**Demostración breve (5–7 min):** pide una estimación; llena un vaso; revela el nivel freático; termina con una idea y un enlace a Groundwater Project.

**Clase (20–30 min con discusión):** 3 min para reservas; 7 min para el vaso; 7 min para la playa; 3–5 min para explicar y comprobar. Añade tiempo para salir al exterior.

Usa **predice → observa → explica**. Pide razones antes de revelar. Deja que las parejas discrepen, prueben y revisen. Mantén opcionales las ecuaciones y la lente. Lee las instrucciones si ayuda; todas las gráficas tienen texto. Los cuestionarios son formativos, con reintentos y sin clasificación. Las respuestas correctas indican práctica de la sesión, no competencias certificadas.
