**Démonstration au salon (5–7 min) :** demander une estimation ; remplir un gobelet ; révéler la nappe ; terminer par une idée clé et un lien Groundwater Project.

**En classe (20–30 min avec discussion) :** 3 min sur les réserves d’eau ; 7 min pour le gobelet ; 7 min pour la plage ; 3–5 min pour expliquer et vérifier. Prévoir davantage pour une sortie.

Utilisez **prévoir → observer → expliquer**. Demandez les raisons avant de révéler. Laissez les binômes débattre, tester et réviser. Équations et lentille restent facultatives. Lisez les consignes si utile ; chaque graphique est accompagné de texte. Quiz formatifs, nouvelles tentatives, sans classement. Les bonnes réponses sont un indicateur de pratique de la session, pas une certification.
