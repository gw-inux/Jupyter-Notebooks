**固定假设：**圆形面积A = 1,000,000 m²，半径R ≈ 564 m，均匀孔隙度n = 0.30，渗透系数K = 5 m/天，井半径rw = 0.30 m。自然最高水位确定均匀补给N。这些是教学假设，不是测量值。

将[Analytical Groundwater Modeling第6.1节](https://interactive-education.gw-project.org/analytical-groundwater-modeling/chap6/6.1_radial_flow.html)的径向势解与[第4.2节](https://interactive-education.gw-project.org/analytical-groundwater-modeling/chap4/4.2_unconfined_interface_flow.html)的界面关系组合。海岸水位固定为海平面；抽水降低水位并抬升井附近计算出的界面。[S15, S17]

将淡水厚度h + z乘以孔隙度，并在圆形面积上积分。未抽水时V = (2/3)nA(1 + α)h₀，h₀为自然最高水位。抽水时采用数值积分，排除很小的井占地。这是储水量，不是可持续开采量。

模型假定稳态、均质含水层、以水平流为主且没有浅层不透水底板。它不解析非完整井附近局部垂向咸水上涌、混合、潮汐或响应时间。滑块使井水位高于原值的一半，这不是安全或盐度标准。[S18]
