#### Data Fitting - Parameter Estimation

In this exercise, synthetic pumping-test data are provided. Adjust transmissivity and storativity until the computed Theis solution matches the observed drawdown and derivative responses.

**Questions to consider**
- Which parameter has the strongest influence on drawdown magnitude?
- Which parameter primarily shifts the response in time?
- How can the derivative help identify a suitable parameter combination?
- Can different parameter combinations produce similar drawdown responses?

The goal of this exercise is to apply the concepts developed in the previous investigations and estimate aquifer parameters from pumping-test data.
